## Source configuration at baseline
- React 18.3, react-scripts 5, Tailwind 3.4, Firebase 10.x, Lucide 0.395. Dependencies as declared in package.json (not a resolved dependency-vulnerability scan).
- Direct Gemini call in `src/api/geminiService.js` uses `REACT_APP_GEMINI_API_KEY` in client bundle and hard-coded model `gemini-2.0-flash`. Client variables are public at build time; treat key as exposed until rotated.
- `src/firebase/config.js` reads `REACT_APP_FIREBASE_CONFIG` and uses analytics eagerly. Firebase web app configuration is not inherently a private secret; permissions depend on rules/auth. Production rules not inspected.
- `src/hooks/useAuth.js`: anonymous sign-in or custom token build variable; no demonstrated account recovery/linking.
- `src/hooks/useFirestore.js`: snapshot listeners on `artifacts/{appId}/users/{uid}/{collection}`, no pagination or explicit ordering.
- `src/features/Sessions/Sessions.jsx`: user message is saved to Firestore **after** AI succeeds; generated exercises create goals in separate writes; error path can leave unsaved user input.
- Existing tabs: Diary, Sessions, SessionSchema, Goals; app state drives page switches, not route URLs.
- Current UI: mostly direct Tailwind utility classes without a consolidated design-token system.
- Tests: package.json exposes CRA test command and testing libraries, but source tree showed no test files.
